Первая версия Cache Out — выборочная чистка данных браузеров по сайтам.

- Chrome, Яндекс Браузер и другие на Chromium, Firefox и его форки: все профили, с аватарками
- По каждому сайту видно куки, историю, загрузки, хранилище и кеш — и можно убрать только нужное
- Отдельно чистятся кеш браузера, формы и адреса
- Перед очисткой делается копия, открытый браузер можно закрыть прямо из окна
- Обновления ставятся сами при закрытии
